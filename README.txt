PORTOFOLIO PLAYFUL — PANDUAN SINGKAT

FILE
- index.html : struktur dan isi halaman
- style.css  : warna, font, layout, dan tampilan responsif
- script.js  : menu mobile, tahun footer, dan animasi scroll

CARA MEMAKAI
1. Ekstrak ZIP ini.
2. Buka folder portfolio-playful di VS Code melalui File > Open Folder.
3. Buka index.html.
4. Jika sudah memasang ekstensi Live Server, klik kanan index.html > Open with Live Server.

SEBELUM DIPUBLIKASIKAN
Ganti teks contoh seperti:
- Nama Kamu
- Nama Universitas / Nama Sekolah
- Nama Organisasi / Nama Kegiatan
- Tahun pengalaman dan pendidikan
- Nomor WhatsApp pada https://wa.me/62XXXXXXXXXX
- usernamekamu untuk Instagram dan GitHub

FORMAT NOMOR WHATSAPP
Gunakan kode negara 62 tanpa tanda +, spasi, atau angka 0 awal.
Contoh format: https://wa.me/6281234567890
Ganti dengan nomor yang memang ingin kamu publikasikan.

CATATAN

- Jangan masukkan password, token, atau data pribadi sensitif ke dalam repository.
- Pastikan semua informasi pengalaman dan pencapaian sudah akurat sebelum dipublikasikan.
